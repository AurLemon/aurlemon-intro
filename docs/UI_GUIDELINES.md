# UI 规范

适用于页面、组件、样式和交互改动。

## 视觉迭代

- 不要在未明确要求时额外添加 hover 浮动、缩放、过强动效或重排版交互。
- 对现有样式做修改时，优先基于用户已改过的版本继续迭代，不要擅自回退视觉方向。

## 首页卡片动态背景

后续首页卡片的逐张改造或整体改造，以已确认的学历卡片效果为视觉基准，沿用以下规则；具体素材根据卡片主题选择。

- 背景优先复用卡片已有的校徽、图标、封面或文字，通过 HTML/CSS 实时组合，不要求额外制作完整背景图。沿用 `InfoCard` 的 `background` 插槽，让背景构图与前景内容保持独立；不因背景改造引入无关依赖或改动前景布局。
- 图案使用固定、可复现的排列，避免随机生成造成 SSR 水合差异或切换时跳动。重复图案整体倾斜约 -12°，相邻行错位半个单元格；常规卡片宽度下以约 7 列为密度参考，宽屏单列卡片限制素材尺寸，避免图标被放大。图案覆盖范围预留旋转和移动余量，卡片裁切后各状态不得露出空边。
- 背景作为低对比纹理，前景图标和文字始终优先。使用以卡片中心为原点的静态径向透明遮罩，中央弱、边缘强：`ellipse at center`，遮罩不透明度依次为 20% 位置的 25%、65% 位置的 60%、100% 位置的 100%。校名或主要文案后方保持安静，边缘保留可辨认的素材细节；通过透明遮罩兼容明暗主题，不叠加固定颜色遮盖文字区。
- 默认状态保持淡色、低饱和度和轻度模糊；hover 或内部键盘聚焦时只小幅增加可见度、减弱模糊，以缓慢移动作为主要反馈。沿用学历卡片的 65% 饱和度、2.5px → 1.5px 模糊、6% → 11% 不透明度作为起点，根据素材实际对比度微调，避免交互时背景突然变成高对比主体。
- 有当前选中项时，仅轻微强调对应素材，其他素材保持原有可见度。强调通过单个素材的不透明度平滑切换，不放大、描边或增加发光；切换内容不重建背景排列、不重置移动进度。学历卡片选中项为默认 12%、交互时 20%，过渡持续 500ms，可作为同类状态的参考。
- 支持 hover 的设备上，交互时以线性速度沿倾斜方向往返移动，参考节奏为 10 秒单程、移动两个单元格。移出后保留当前位置并暂停；离开视口或页面隐藏时暂停；减少动态效果偏好下禁用移动与渐变过渡，保留静态选中状态。背景不接收指针事件，并从无障碍读取中排除。
- 持续移动仅动画 `transform`，状态切换优先动画 `opacity`；模糊只在交互切换时短暂过渡，径向遮罩保持静态。复用相同素材 URL，避免额外背景下载。验证须检查实际浏览器中的静态、hover、选中项切换、明暗主题、手机与桌面尺寸及减少动态效果；Build 通过不能代替视觉和交互验证。

### 学历卡片实现参数

- `EducationCardBackground` 复用当前四个学校校徽；单元格尺寸为 `clamp(36px, 14cqw, 64px)`，校徽占单元格宽度的 88%，使用 20 列 × 8 行的固定重复图案提供裁切与移动余量。
- 当前学历阶段对应的全部背景校徽使用选中项不透明度，其余校徽使用默认值；语言切换不改变选中学校。其他首页卡片在实际改造前继续使用现有背景图，改造时遵循本节规则。
- 首页前景、预加载和动态背景共用原始校徽的 `?w=320&q=90&thumbnail` 导入结果，原图保留在 `assets/resources/school_badge/`。缩略图由通用构建模块按需生成至 `.nuxt/thumbnails/`，产物不进入 Git；宽高上限 320px、WebP 质量 90、透明通道质量 100，保留透明背景且不放大原图。当前四张合计约 109.2 KiB，低于 400 KB 的首页预算；按当前 80px 前景校徽保留最高 4 倍像素密度，不为背景重复下载原图。后续卡片使用同样的参数化导入，详见 [本地图片缩略图](DEVELOPMENT.md#本地图片缩略图)。

## 首页学历校名

- 各 locale 的教育阶段使用 `title` 保存全称、`shortTitle` 保存可选简称；空字符串表示直接展示全称。英文校名依据学校官方资料、校徽或政府译名，不自行扩写缩写。
- `EducationSchoolName` 只在实际溢出时播放：有简称时先展示简称，简称本身也放不下才截断并显示省略号，停留 3 秒后交叉淡入全称；全称首尾各停留 1.2 秒，中间以 56px/s 线性向左移动，按阅读顺序展示到末尾，再淡回简称。没有简称时全称独立循环，能放下时保持静止。
- 切换语言、教育阶段、字体或容器宽度后重新测量；悬停、键盘聚焦、离开视口及页面隐藏时暂停。减少动态效果偏好下展示静态全称，溢出内容可手动横向滚动。
- 英文简称单独配置在 `shortTitle`，不在全称后重复附加括号缩写；滚动全称使用左右各 24px 的透明渐隐遮罩，并预留对应内边距，让首尾文字在停留时完整可见。简称和能放下的静态全称不加遮罩。
- 学历阶段右侧使用两条描边组成的向下箭头，卡片悬停或内部键盘聚焦时淡入，不改变原有文字对齐。有简称时保留校徽与校名组合平滑收拢、展开的视觉效果：文字列固定为全称所需宽度，校徽与全称使用 `transform` 配合淡入淡出，不逐帧修改列宽或缩放字形。测量依据独立的原始文本宽度和卡片可用宽度；字体或尺寸通知只有在测量结果实际改变时才重建动画，避免无关字体加载打断播放。
- 语言和阶段共同作为学历卡片内容切换键，使用原有淡出后淡入过渡，让新语言的校名与副标题一起初始化；重新测量期间保留旧动画，尺寸就绪后同一帧替换，避免可见的列宽回弹。
- 旧校名卸载时，保留已测量的静态列宽，先冻结当前动画帧的透明度和位移，再清理动画；离场过渡保留的旧 DOM 不得回退到全称自然宽度。

- 教育阶段的补充小字仅中文显示：专科为“3+2 高职阶段”，高中为“3+2 中职阶段”；其他语言的 `hint` 使用空字符串，避免回退到中文。英文专科副标题仅展示年份，不附加 `DIPLOMA`。

## 品牌签名动画

- About 页的签名首次进入视口时播放一次：去掉整字描边提示，高亮与手写同时开始，高亮铺开 360ms，手写持续 2600ms，完成后保留静态标记，不循环擦除。
- `SiteMark` 通过 `duration` 和 `highlightDuration` 配置当前使用位置的节奏；动画默认时长为手写 4000ms、高亮 900ms，footer 使用静态标记，不播放动画。动画保留转弯减速，减弱连笔提速并平滑相邻速度采样，缩短抬笔停顿；减少动态效果偏好下静态展示。

## 样式实现

- HTML 结构中，非必要不要直接写 `style` 内联样式，优先使用 Tailwind CSS 与 Nuxt UI 提供的能力完成样式表达。
- `<style scoped>` 不是禁用，但应只用于 Tailwind CSS / Nuxt UI 难以表达的复杂状态、动画、第三方组件覆盖或结构性样式；普通布局与视觉优先留在模板 class。
- `:style` / 内联 `style` 只用于运行时计算值、第三方库注入 HTML、canvas / map 等 Tailwind CSS 无法静态表达的场景；静态样式不要回退成 inline style。

## 主题与 Design Token

- 优先复用 `app.config.ts` 中的 Nuxt UI 主题配置，以及 `assets/styles/base/tailwind.css` 中的 design token，不要在页面里重新发明一套颜色、表面层级、尺寸语义。
- 颜色、语义色、表面层级、字号与字体倾向，优先通过 token 与 class 表达，不要在局部组件里散落硬编码色值。
- 对 Nuxt UI 组件的定制，优先走 theme / config / class 扩展，不要为了一个局部视觉点把整个组件手写替换掉。
