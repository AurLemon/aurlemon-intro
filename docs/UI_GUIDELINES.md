# UI 规范

适用于页面、组件、样式和交互改动。

## 视觉迭代

- 不要在未明确要求时额外添加 hover 浮动、缩放、过强动效或重排版交互。
- 对现有样式做修改时，优先基于用户已改过的版本继续迭代，不要擅自回退视觉方向。

## 首页卡片动态背景

六张首页卡片统一使用重复素材背景，旧的整张背景图已经删除。`InfoCard` 只负责前景布局、边框、背景插槽与内容切换，不再提供 `backgroundSrc`、`backgroundBlur` 或 `darkInvert`。

### 移动端与桌面模式

- `useDisplayMode` 是布局与动效模式的统一入口：`isCompact` 使用 `< 64rem`（与 Tailwind lg 一致）决定布局；`isMobileMotion` 在窄屏或缺少 hover + fine pointer 时使用轻量动效。`plugins/display-mode.client.ts` 只在 hydration 完成后同步共享状态，并监听媒体条件变化；SSR 与首次 hydration 保持一致，必要的窄屏静态 CSS 在同步前已经生效。不在业务组件内重复维护不同的“手机”断点。
- 桌面保持双层背景、完整平铺周期与原有交叉淡化；轻量模式只渲染普通状态一层，平面只保留旋转与滤镜余量，取消漂移和常驻 will-change。布局与平铺尺寸计算位于 `useCardPatternLayout`，素材、透明度与档位仍沿用 `cardPattern.ts`。
- 触摸不触发卡片 hover，指针焦点不展开上方导航提示；键盘通过 focus-visible 保留可达性。窄屏不在卡片内挂载导航提示，改由 `MobileCardNavigationStack` 投放到 Header 下方。`useMobileCardNavigationStack` 将候选范围与当前阅读位置分开：IntersectionObserver 维护可见卡片，至少一半卡片进入扣除 Header 提示区与底部菜单留白后的可阅读视口才成为导航候选；六张卡片共同按中心距离划分阅读区域，以屏幕高度约 40% 的位置选择当前卡片，进入夜间、语言等无导航卡片的阅读区域或离开卡片整体范围时收起整栈。同屏候选最多堆叠三条，仅当前阅读卡片提升前排，后层保留既有顺序，新候选按距阅读位置远近补入，避免随滚动反复换位，切换时仍有效的候选保留，离开候选范围才退场，不保留滚动历史。卡片文档坐标仅在布局、字体或视口变化时缓存，滚动每帧最多根据缓存坐标和 scrollY 更新一次，不逐帧测量卡片。停滚 180ms 后启动整栈 4 秒收起计时，滚动期间暂停；收起后同一阅读区域的轻微滚动不再次展开，阅读卡片变化才允许重新展示。离场使用轻微 translateY 与 opacity，不压扁缩放、不等待停滚。统一 18rem 宽度（不超过可用宽度），参考 Nuxt UI Toaster 的错位与每层 5% 缩放，以实色表面、边框和小阴影表现堆叠，不降低后层透明度；只动画 transform / opacity，沿用入场及换位 transform 240ms、opacity 180ms 和退场 180ms 的曲线与时长，上下 padding 为 5px，不使用 UNotifications。离开页面、模式切换及页面隐藏时清理观察器、动画帧和定时器。宽屏轻量模式的导航提示不播放尺寸、裁切和模糊动画。Header blur 与底部浮动菜单保留用户确认的原有视觉效果；先通过背景、布局和触摸触发范围降低开销，不默认删除这两处效果。
- ACG 与音乐离开视口时暂停轮换和作品名滚动，返回后继续剩余阅读时间，弹窗与页面隐藏暂停叠加处理。真实下一张封面通过 `prepareCardCover` 提前下载与解码，切换仍等待准备完成，失败不消耗队列。轻量模式作品名按实际内容与宽度上限计算，短内容收缩、长内容滚动；只在内容/布局变化时更新宽度，不播放 width 过渡，桌面保留既有宽度过渡。
- 窄屏学历卡片校徽靠左、文字列占满剩余宽度，始终使用全称并在溢出时滚动，不播放校徽与简称组合收拢；桌面保持原行为。学校文字的动画关键帧独立放在 `educationSchoolMotion.ts`。
- 首页少量前景图片使用 eager；`SkeletonImage` 的 `revealCachedImmediately` 仅由已预解码图片的调用方按需启用，已缓存且完成解码的图片直接展示，其他调用方仍保留默认 lazy 和渐显。不把全站图片改为 eager。
- 性能验收必须额外覆盖首次进入后立刻从顶部滑到末尾、连续上下滑动、卡片首次露出、菜单显隐与偏好轮换；生产 trace 用于性能判断，Dev 只用于快速检查。短距离热页面对照与 Build 都不能证明完整移动体验通过。

### 共用层与默认值

- `CardPatternBackground` 统一接管固定排列、密度、列错位、倾斜、遮罩、明暗配色、透明度、模糊过渡、阴影、滚动、视口/页面隐藏暂停与减少动态效果。素材组件只负责校徽、图片裁切或 SVG 镂空，不自行复制动效和视觉参数。
- `components/cards/cardPattern.ts` 是参数唯一入口。`visibility` 表示与主题底色的目标 RMS 色差，不是 CSS opacity；默认浅色 0.036、深色 0.057，hover/内部聚焦分别为 0.075、0.0762。教育背景不随学历选择高亮或压暗，切换只更新前景校徽与文字。已删除无调用方的 selectedMotif、背景分层选中高亮及独立选中透明度配置。六张卡片使用相同基础目标，素材差异通过公共档位处理，不在卡片内散落独立数值。浅色视觉强度略弱于深色；具体 CSS opacity 可能反而更高，因为浅色底与灰色素材的对比更低。
- 每个素材独立计算 `opacity = min(0.6, visibility / contrast)`，纯透明或与底色完全同色的素材保持不可见，不无限放大。使用亮度权重的 sRGB 色差 RMS 作为项目内的近似视觉指标，包含透明覆盖面积、色彩和饱和度调整效果；它不保证不同图案的主观观感完全相等，也不是正文 WCAG 对比度。静态径向遮罩与阴影仍统一施加，不把前景附近的刻意渐隐补偿回来。
- `build/card-appearance/nuxt.ts` 在 Dev/Build 中按 48px 单元格、42px 素材测量各主题；色票读取当前 `assets/styles/base/tailwind.css` 的 surface-0、neutral-500/400。素材先按实际 contain/cover 裁切、保留 alpha、按共用 `saturate(1.15)` 增强饱和度，再模拟 Gaussian blur，输出色差和梯度 RMS 的保留率。测量只在构建侧发生，不由客户端逐张下载原图或用 Canvas 分析。
- 模糊统一以 64px 单元格为配置基准：普通状态 3px，hover/内部聚焦 1.5px，实际值按 `clamp(36px, 14cqw, 64px) / 64` 同比计算。采样表按 48px 单元格换算并线性插值色差，再反算透明度；不会继续用边缘保留阈值把用户设定的模糊压到过小，也不会让静态与 hover 算成相同值。构建输出的边缘保留率作为测量元数据保留。SVG 文本采样使用构建主机 serif 字体，浏览器继续用项目 serif 字体，字形差异会带来小幅测量误差。
- 公共档位位于 `cardPattern.ts`：`blurLevel` 的 `clear / standard / soft` 分别乘 0.65 / 1 / 1.15；`strengthLevel` 的 `quiet / subtle / standard / distinct` 分别乘 0.5 / 0.8 / 1 / 1.2。先继承公共默认值和部分字段覆盖，再应用档位。技术、夜间与语言当前使用 `density: 1` 和默认 standard 档位，语言文字字号为 18；ACG 与音乐都使用 clear + distinct，保持相同目标可见度；教育使用 standard + subtle 和 `density: 0.95`，较默认 0.8 略密，在常见桌面卡片宽度下约多一列，保持更柔和的校徽背景。
- `options.density` 按比例缩小单元格；布局测量、模糊与移动距离同步使用该单元格尺寸。`columnStep` / `rowStep` 分别独立控制横向列距和纵向行距，默认均为 1 个单元格，不改变素材大小；图片背景默认按素材显示宽度加 0.12 格留白计算，竖版封面为 0.62 + 0.12 = 0.74，未指定尺寸的方形图片仍为 1，可通过 options 覆盖列距。音乐通过 `imageWidth: 0.62` 与 ACG 使用相同显示宽度、density 0.7 和 0.12 格间隙，正方形素材行距为 0.74，不沿用竖图的 1 格行距。音乐使用 catalog 排列，四列、八行覆盖全部 29 张，补齐空位的少量图片重复；悬停以原速度持续向下滚动完整八行周期（40 秒），循环接缝与起点图案重合。其他背景同样移动各自完整的平铺周期，保持既有排列。`options` 按需提供 `light`、`dark` 的目标可见度与参考尺寸 blur、`shadow` 部分字段，以及 `transitionMs`、`driftSecondsPerRow`。未提供字段继承公共默认值。常规卡片只传素材和构建输出的 `profiles`，不得再手填每个素材的透明度。色票、图片或 SVG 清单修改后重新生成测量结果。
- 普通与 hover 各渲染一份固定 blur、固定素材 opacity 的 SVG 图案，hover 用外层 HTML 的 500ms ease-out opacity 交叉淡化模拟清晰度与强度变化。禁止逐帧改变重复 SVG 素材的 opacity 或 blur/filter；这会让快速换卡片时的退场过渡一起重绘。两份图案共享素材 URL，不增加下载。主题数值在挂载后读取 `useColorMode`，SSR 与首次 hydration 使用相同默认值，避免深色主题样式不一致；素材内联取值，不依赖 SVG use 引用树的祖先主题/hover 选择器。教育菜单打开时通过 `focusActive` 关闭焦点播放，保持既有交互。
- 四类素材通过 `motifs` 和 `motif` 插槽接入：`EducationCardBackground` 只传校徽与测量值，`TechnologyCardBackground` 和 `PersonalCardBackground` 通过 `SvgCardBackground` 使用受信任的本地 `*.card-motifs.json?appearance` 清单，渲染和测量共用同一份 SVG，`ImageCardBackground` 从一个图集 URL 按区域裁切。六张卡片的每个静态状态均合并为一个 SVG pattern 层；教育阶段切换不改变背景图案或强度。图案层数不等于图片请求数。公共层统一交互和视觉参数，素材层保留不同的外轮廓，不要求每个主题都套相同的圆角底块。

### 排列、阴影与交互

- 六张卡片的背景漂移使用 `useCardPatternDrift` 控制 CSS 线性循环的播放速率，hover / 有效焦点进入时由 Motion V animate 在 480ms 内以 easeInOut 从 0 加速到 1，然后保持原有速度和完整平铺周期。只在起步阶段通过 Motion V onUpdate 修改 Animation.playbackRate，不逐帧重算 transform 或 SVG；暂停保留相位，再进入时重新加速。离开视口、页面隐藏、轻量模式或减少动态效果时停止并清理 Motion V 起步动画，移动端保持静态。
- 固定排列避免 SSR 随机差异。倾斜 -12°，相邻列上下错半格；单元格 `clamp(36px, 14cqw, 64px)`，素材占 88%，补齐跨边界半格。绘制平面通过 ResizeObserver 按卡片逆旋转后的包围盒计算，横向加一格滤镜余量、纵向加两个完整平铺周期及一格滤镜余量，避免固定绘制 20 × 12 格。前景尺寸与文字布局不随背景调整。
- 静态径向透明遮罩使用 `ellipse at center`：20% 位置不透明度 25%、65% 为 60%、100% 为 100%。前景后方保持安静，不叠加固定颜色盖住文字。
- 所有六张背景素材的阴影统一在共用组件 SVG `g` 上复用 `feDropShadow`。默认以单元格为坐标：水平偏移 0、垂直偏移 0.025、标准差 0.022，浅色 `slate-700`、深色 `slate-950`、阴影不透明度 55%。阴影仍受整体透明度、模糊与遮罩约束；校徽按真实透明轮廓投影，镂空图案保留空洞边缘，不叠加第二套阴影。
- hover/内部聚焦时沿倾斜的列方向持续向下移动，默认每行 5 秒；移动距离自动取 SVG pattern 的完整纵向平铺周期（`tileRows × rowStep`），周期时长为 `tileRows × driftSecondsPerRow`，使用 linear infinite 单向动画，结束位置与起点图案完全重合，实现无感循环，仅持续动画 `transform`。移出保留当前位置；离开视口或页面隐藏暂停。两份静态图案同步移动，模糊和素材强度在每份图案内部保持固定，仅外层状态 opacity 与移动容器 transform 动画。只对这两个明确的动画容器使用 will-change，不向全部 SVG 节点添加；可见性观察稳定的卡片盒，不观察带遮罩的背景；离开视口、页面隐藏和减少动态效果时释放提示。
- 装饰背景不接收指针事件且隐藏于无障碍树。减少动态效果时禁用滚动和渐变过渡，保留静态背景。验证覆盖静态/hover、教育阶段切换、明暗主题与窄屏；Build 不代替浏览器验收。

### 图片清单与请求预算

- 首页素材统一放在 `assets/resources/homepage/` 的六个子目录：`education / technology / acg / music / night / language`。各卡片的图片清单和 SVG 清单与素材同目录，统一命名为 `background.card-atlas.json` 或 `background.card-motifs.json`，前景单图为 `cover.svg` / `cover.webp`；教育目录保存四个校徽。ACG 封面使用作品名与卷数命名，统一保存全尺寸 WebP，条目来源仍可通过清单 id 中的 Bangumi 编号追溯。

- ACG 和音乐分别使用 `assets/resources/homepage/acg/background.card-atlas.json`、`music/background.card-atlas.json` 保存实际素材清单：每项包含稳定 `id` 和相对清单的本地 `file`。ACG 使用用户选定的六张 Bangumi 竖版封面（本地 `acg/`），通过清单 `fit: "portrait"` 固定宽度并按原图宽高比自动计算高度，不裁切；音乐背景使用用户提供的二十九张网易云封面直链，清单 `source` 字段保留来源记录，构建与浏览器不会从这些直链实时抓取；前景通过 `MusicCardCover` 从同一清单的 `?covers` 导出中只显示一张 320px 缩略图，`cover.webp` 已删除。不自动抓取网络图片、不临时填充示例素材。
- 使用静态导入 `import atlas from '~/assets/resources/homepage/acg/background.card-atlas.json?atlas'`。`build/card-atlas/module.ts` 在 Dev/Build 中解析清单；单图复用已有 `?w=320&q=90&thumbnail` URL，单图模式前景和背景复用同一个资源；多图模式背景图集与按需前景缩略图各自独立。多图构建为一个 WebP 图集，每格 160 × 160，最多 32 张，单图集不超过 200 KiB，质量 85。图集只写入已忽略的构建目录 `card-atlases/`，原图保留，最终 URL 由 Vite 打包并缓存。清单可设置 `fit: "contain"` 在透明方格内完整容纳图片；ACG 使用 `fit: "portrait"`，图集区域宽度固定为 112px，高度按原图宽高比等比缩放，打包行高按最高素材自动扩展，不随机、不裁切、不拉伸。显示宽度统一为单元格的 62%，高度按区域比例变化，ACG 与音乐均使用 `density: 0.7`，较公共 0.8 在同宽卡片上约少一列，其他公共参数保持不变；默认 `cover` 保留既有方形裁切。
- 多图的 `CardImageAtlas` 只含一个 URL、尺寸和裁切区域；客户端不接收原图 URL 列表，不对每个格子发起独立请求。尺寸与裁切在构建时确定，浏览器仍实时做列排列、旋转与移动，不能把图集理解成旧式整张背景图。
- 图集按清单、原图内容、尺寸和 sharp 版本计算缓存指纹。清单或已引用素材变化时 Dev 刷新并重建；缺失、不支持、重复 id、超过数量或体积预算时明确报错。仅支持仓库 `assets/` 内静态 PNG/JPEG/WebP/AVIF，不在请求处理时现场拼接图片。
- 教育的四个校徽本来就供前景切换使用，前景、预加载和背景共享 320px/q90 缩略图 URL，重复图案不增加独立下载；保留用户已确认的预加载行为；`*.webp?appearance` 仅导出分析数值，不生成另一张图片。技术、夜间与语言背景使用内联 SVG/文字，不新增图片请求。后续下载用户选定链接后保存原图并修改清单即可；需要自动更新时另行设计定时获取、生成、原子发布与失败时保留上一版，不默认加入后端更新服务。

### 前景布局与颜色

- 六张卡片的前景图统一由 `InfoCard` 的 logo 插槽容器禁止选中与原生拖拽，覆盖图片、SVG、Emoji、学历切换及偏好轮播的进出场图层；保留其他文字与链接的交互。`select-none` 只限制选中，不能单独阻止图片拖拽；容器同时阻止 `dragstart`，图片补充 `-webkit-user-drag: none`。

- 六张卡片继承 `InfoCard` 的同一套外边框和文字颜色：外层 `h-40 rounded-xl border-6 border-slate-200 dark:border-slate-800`；标题 `text-slate-800 dark:text-slate-300`，副标题 `text-slate-700 dark:text-slate-400`。技术卡不再单独覆盖为更浅颜色。背景滚动、图片分类和副标题切换不得改变主标题。
- ACG 与音乐前景使用完整的 80 × 80 容器，外层 `rounded-lg overflow-hidden`，使用 `bg-slate-200/60 dark:bg-slate-800/60` 作为图片加载、失败与切换时的颜色兜底；常驻边框覆盖层使用 `border-slate-300/60 dark:border-slate-800/60`，与夜间、语言前景保持相同主题配色；图片贴满边缘，不加 margin、padding 或会挤占图片的布局边框。ACG 内层封面只使用 `rounded-sm`，层间有阴影，阴影不能漏出容器。教育背景也按内圆角裁切；教育菜单仍可溢出前景，不能直接裁掉整个 InfoCard。

## 首页卡片导航提示

- 仅教育、技术、ACG、音乐四张卡片提供上方导航胶囊，分别链接本地化的 `/profile`、`/project`、`/preference`、`/preference`；后两张不提供。文案同步维护三种语言的 `main.index.card.navigation`，ACG 与音乐使用独立提示；通过 i18n-t 的 page 插槽将页面名显示为 font-bold 并加 px-0.5，浅色使用 slate-800、深色使用 slate-100；其余提示文字使用普通字重与 slate-500 / slate-400，hover 不将整句染成主色。指针移入小条或键盘聚焦时，外壳背景浅色从 surface-0 切到 surface-1、深色从 surface-1 切到 surface-2，以 180ms 颜色过渡提示可点击；不因指针仍在大卡片内而提前触发小条背景变化。
- `InfoCard` 的 `navigation` 插槽位于 z-3 前景层内部，与学历菜单和偏好弹窗共用层叠上下文；导航小条 z-4，弹窗 z-[40000]，避免弹窗被更高的祖先同级导航盖住。导航仍保持绝对定位、不占前景布局。插槽承载 `CardNavigationHint`，使用 Nuxt UI `UButton`；提示条绝对定位，不占布局空间，不修改卡片尺寸或网格间距。仅所属卡片 hover 或内部键盘聚焦时展开，提示条居中压在卡片上边框中线，仅实际宽度响应指针，左右留白不扩大 hover 区域。
- 外壳、箭头、文字常驻 DOM，Motion V 统一控制显隐与外壳展开。入场外壳立即以 spring（stiffness 180、damping 20、mass 0.9）展开，120ms 后用 380ms 淡入，同时以 500ms 从 blur(4px) 变清晰；独立动画容器从 -2px 回到原位，以 spring（230 / 12 / 0.7）产生一次轻微回弹，不缩放边框或圆角。退场用 320ms 先淡出，外壳与内容裁切同步用 800ms 收拢，不让用户看到收至最小后的残留胶囊；模糊与位移在淡出结束后复位。外壳按实际宽高变化保留真实 rounded-full 与 2px 边框，按钮占位固定。仅文字和箭头容器使用 overflow-hidden 和同步 clip-path，不裁切边框；不加阴影、不测量尺寸、不逐帧执行自定义 JavaScript。箭头保留 SVG 描边入场与 1400ms 周期、左右各 0.5px 的轻摆，文案与箭头入场延迟为 360ms、300ms。连续 hover 4 秒后自动收起，移出再移入重置；卸载清理定时器，隐藏链接退出 Tab 顺序。减少动态效果时 Motion V 时长为 0，关闭箭头轻摆。

## 浮动菜单与首次交互性能

- 小于 lg / 64rem 时，底部导航仅显示「两条横线 + 当前页面本地化名称 + 向上 Chevron」胶囊，沿用原导航的主题表面、边框、阴影、高度、底部位置、滚动跟随与显隐动画。弹层与桌面共用 displayNavItems，包含五个基础项及当前额外页面，使用固定 14rem 宽的向上 UPopover 并沿用 Nuxt UI 默认表面样式；菜单项使用 16px 文字、页面图标及右侧选中勾，以区别卡片内的局部选择菜单。外显文字随当前页或语言变化交叠淡化、轻微位移与模糊切换；点击入口、再次点击按钮、点击外部或按 Escape 收起，路由变化、菜单隐藏和布局模式切换也关闭弹层。外显文字及左侧图标使用 primary / dark:sky-300 高亮，菜单文字保持 slate-800 / dark:slate-300；胶囊图文间距为 8px。新增页面图标与 Chevron 在 nuxt.config.ts 的 icon.clientBundle.icons 中显式打包，避免运行时单独请求。Chevron 使用轻量旋转，减少动态效果时关闭。外壳根据独立隐藏测量的当前页文字与图标计算目标宽度，保留 500ms width 过渡，弹层展开不改变外壳尺寸；宽屏继续使用原横向导航。

- 浅色模式下，全站 Header 的阅读进度文字、中央标题、主题与语言按钮图标、弹出菜单未选中文字统一为 slate-800；进度环主色、菜单选中态和辅助徽标保留各自语义配色，深色模式沿用现有颜色。
- Header 的主题、语言按钮及弹出菜单图标局部使用 `UIcon mode="svg"`，保留现有 clientBundle 图标清单。CSS 模式首次挂载图标会插入运行时样式表；本机 Chromium 采样中这会触发已有字体重新加载，让首页 Emoji 短暂回退并改变宽度。不要通过给 Emoji 固定宽度或增加全页合成提示掩盖这条触发路径，也不将局部修复扩展成全站图标模式切换。
- 浮动菜单不添加点击回弹，保留原有滚动 spring 动效。文字 hover 变蓝与移出恢复使用 200ms ease-in-out 颜色过渡；桌面选中项的 400 ↔ 600 字重使用 350ms cubic-bezier(0.22, 1, 0.36, 1) 过渡，显式声明 color 与 font-weight，避免仅 transition-colors 导致字重硬切。减少动态效果时关闭。
- 桌面菜单外壳按五个基础项容器的 offsetWidth 加额外项的目标宽度计算，不使用会包含绝对定位高亮溢出的 scrollWidth；高亮退场或语言变短时不会把旧宽度缓存到外壳。额外项与外壳统一使用 500ms 曲线并直接过渡到最终宽度，ResizeObserver 仅观察基础项容器与隐藏测量文字，不追踪额外槽的逐帧宽度；额外项前的间距计入槽宽一起收起，槽常驻且在 width transitionend 后清理旧链接，快速切页仅清理仍处于收起状态的内容。页面选中判断使用去掉语言前缀的路径，避免 locale 与路由更新不同步时临时插入额外当前页菜单项。
- 选中高亮和指针预览使用常驻的普通 DOM，位置、按压缩放与淡化交给原生 CSS 过渡；不要每次进入菜单重新挂载 Motion/AnimatePresence。宽度仅保留菜单项尺寸变化所需的 220ms 过渡，位移 380ms、透明度 180ms；减少动态效果时关闭过渡。合成提示仅用于这两个小型高亮，不扩散到所有导航节点。
- 菜单项局部位置和尺寸在 `syncPills`（初始测量、菜单布局、语言、路由变化）时缓存；pointermove 只保留最新坐标，每帧最多读取一次视口和 inner 的变换后边界，不重复遍历读取每个链接的 getBoundingClientRect。离开菜单或卸载时取消待处理帧；保留触摸横向拖动、拖动后禁止误导航及键盘聚焦行为。
- 首次导航的卡顿需分别测量路由确认、内容挂载和菜单动效，不能把页面组件的主线程长任务全部归因于导航。Dev 首次模块编译、首次 hydration 与后续热导航不等价；帧采样/Long Task 只能辅助定位，不冒充完整 DevTools trace。
- 项目页贡献日历的真实色块保留普通 span，通过容器委托事件、日期索引与一个 UTooltip reference 显示日期和次数；不为一年约 365 个色块各初始化一套 Tooltip。指针提示保留 50ms 延迟，支持键盘聚焦；退出色块、滚动、重新加载和卸载时关闭并清理定时器。日期格式器按 locale 复用，数据获取保持不变。贡献图去掉外框与内边距，账户和 Commits 数量置于格子下方，数量 Tooltip 用不含标点的一句话显示统计起止日期，日期采用年月日或英文完整月份，账户名沿用普通字体，hover 仅加深用户名文字，图标不变色、不使用主色高亮。按视口计算整列格子尺寸，隐藏滚动条，每周固定七格，范围前后的空位（含本周尚未来临的日期）以中性色块补齐，不伪造贡献记录或计入总数。挂载、数据更新与尺寸变化后以 instant 定位到最右端，默认显示最新日期；悬停、键盘聚焦或触摸时渐显两侧可用的导航按钮，支持滑到最早日期。贡献图不渲染渐变遮盖层；按完整周列宽度翻页，使用 scroll snap 并在 scrollend 校正列位置，避免停在半格。

## 内容页面布局

- 页面切换保留原有 220ms opacity + 6px translateY 过渡，不改变既有动画效果。首页与内容页不同的顶部留白放在 NuxtPage 插槽的页面过渡层内，依据该插槽的 route 判断，不能跟随全局 route 修改常驻 main 的 padding，以免旧页面淡出前先被新页面的间距推移。过渡层以插槽 route.path 作为 key；入场期间 page-enter-active 保持透明，由 onEnter 在插入后的下一帧通过 Web Animations API 显式播放 opacity 0 → 1 与 translateY(6px → 0)，并以 both 填充首尾状态；动画时钟在页面挂载后才启动，完成后调用 Vue 的 done 并清理 Animation，取消入场时同步清理。不再依赖 enter-from / enter-to 两次样式提交、强制布局读取或挂载期间已经开始计时的 CSS animation。退场继续使用原有 CSS transition。减少动态效果时直接完成入场并关闭退场 transition。不要逐帧读取布局，也不要仅靠 key 或读取样式的验收脚本判断入场已修复，必须抓取不读取 computed style 的真实中间画面。跨页面的滚动位置恢复通过 page-scroll 按目标路径等待页面过渡的 onEnter，并在插入后的下一帧恢复平滑滚动；记录已就绪路径，避免同步页面先触发入场导致等待丢失，快速切页时拒绝过期恢复。减少动态效果时使用 instant；保留浏览器历史位置、每页位置缓存和原有锚点行为。

- 桌面端（lg 起）全站 Header 中央通过 `ReadingPageTitle` 显示当前内容页的短标题，排除概览和友链页。使用 16px sans、600 字重、0.06em 字距，英语强制大写，常驻绝对定位的居中容器为两侧控件预留空间。初始隐藏；按 ContentHeader 底边与 sticky Header 底边判断显隐，整个 ContentHeader 滚出可见区域后，常驻标题通过 Motion V 从 5px 模糊和 0.96 缩放显现，transform 使用 300 / 20 / 0.8 的弹簧参数产生轻微回弹，模糊 300ms、透明度 200ms 独立 tween；返回页头时以 200ms 模糊、轻微缩小和淡出退场。只动画这一行文字，不测量或动画布局，不常驻 will-change。显示文案与英文大小写使用快照，切页或切语言时先退场，在 Motion V 的退场完成回调中切换到最新文案再入场；连续切换只采用最终文案，不用计时器猜测动画结束。窄屏不显示；被动滚动事件通过 requestAnimationFrame 合并为每帧至多一次位置校验，路由（含 hash）、语言、视口、页面完成及过渡完成、历史恢复时同步。MutationObserver 仅观察正文容器，DOM 替换后重绑当前页面的页头；ResizeObserver 处理页头尺寸变化。卸载时清理事件、观察器与动画帧，减少动态效果时取消过渡。
- 非首页统一使用 `ContentHeader`：黄脸表情 Emoji 放在左对齐衬线标题上方，不显示页面简称、解释性副标题或装饰分隔线。各语言标题使用与表情语义对应的短句，不强制换行；中日文保留较大字号，英文沿用原字号，三种语言统一使用 font-semibold（600）字重。三语言标题位于 `main.contentPages`。
- `ContentMetadata` 只用于页头，以 text-sm 显示“字数 / 分钟”。文末 `ContentFooter` 保留原有居中布局、字体、字号、history / file-text 图标、更新时间和阅读统计，“创建于”使用 calendar-plus 图标并与“更新于”相邻排列，窄屏自然换行。日期按 Asia/Shanghai 展示，默认只显示数字年月日；hover 或键盘聚焦时通过 UTooltip 显示精确到秒的完整时间，保留原有图标、字体和排列。
- `ContentPage` 组合页头、可选 `overview` 插槽与正文，依靠适度留白衔接，不额外添加正文上方的分隔线。全站沿用原有横向留白：PageContainer 使用 px-6；Header 与 Footer 使用 px-6 lg:px-0，均保留 max-w-4xl。内容页 ContentHeader、overview 插槽、Markdown 正文 ContentContainer 和友链卡片列表不再添加横向 padding，统一由 PageContainer 的 px-6 提供留白，与首页对齐。ContentPage 的 overview 通过 ContentHeader 默认插槽渲染在页头内部，不另设页头外区域。项目页仅将 GitHub 贡献日历放入 overview；作品集在三语言 Markdown 的“发展路径”之前以 `::project-portfolio` MDC 组件调用，展示三个真实站点截图及仓库、网站链接，卡片描述采用用户第一人称简介，并以对应 GitHub 仓库补充功能事实，同步三种语言；作品集卡片内文字按用户要求使用 word-break: normal，仅在长项目名或连续字符溢出时通过 overflow-wrap: anywhere 兜底，不继承正文的 break-all。项目名后显示用户指定的起始年月 badge（2024/11、2026/7、2024/4），GitHub 链接 hover 仅加深中性文字色，不变蓝；整卡链接到站点，GitHub 链接独立可点，悬停或键盘聚焦时整卡背景变暗、图片亮度降到 90%，不缩放图片。作品集截图使用用户提供的原尺寸素材，构建时生成缩略图，原图完整保留，卡片图片通过绝对定位与 object-cover 铺满固定 3:2 图片区域的宽高，文字区域使用透明背景，由卡片外层统一执行一次 hover 底色过渡，避免双层颜色过渡叠加。卡片与横滑区域分别隔离层叠上下文，内部链接不越过边缘遮罩。窄屏（小于 lg / 64rem）作品集每张卡片固定占满可用宽度，每次停稳只显示一张，通过原生横向触摸滑动和 scroll snap 切换；作品集与贡献图均隐藏窄屏图片区域上的按钮与遮罩，首屏即由 CSS 生效，不等待 hydration。窄屏作品集下方居中显示“左箭头 当前页/总页数 右箭头”，使用 xs 小按钮，首尾禁用相应方向；触摸滚动、按钮切换与尺寸变化同步更新当前页，宽屏隐藏底部分页。宽屏支持横向滑动与按钮导航，有溢出的左右边缘持续使用渐隐遮罩，遮罩与按钮显隐独立，滚动边缘采用显示大于 2px、隐藏不大于 0.5px 的分离阈值，避免亚像素抖动反复打断淡化。作品集与贡献图导航沿用 ImageCarousel 的圆形按钮、阴影与背景模糊，按钮缩为 32px、箭头 16px。按钮与边缘遮盖层常驻，按钮沿用 200ms 显隐，边缘渐变以 400ms transform 沿各自方向滑入、撤回，消失时只关闭交互，不用 visibility 或离散 mask 切换提前截断退场；两处轮播遮罩统一加宽至窄屏 96px、桌面 128px，并在边缘保留 15% 实色段；友链页保留原有 6px 边框、悬停描边与 lg 双列卡片，登录和申请入口位于列表下方的原有底部区域，不放入页头。

- `SiteMark` 通过 `duration` 和 `highlightDuration` 配置当前使用位置的节奏；动画默认时长为手写 4000ms、高亮 900ms，footer 使用静态标记，不播放动画。动画保留转弯减速，减弱连笔提速并平滑相邻速度采样，缩短抬笔停顿；减少动态效果偏好下静态展示。

## 样式实现

- Nuxt Icon 在 `app.config.ts` 统一使用 `icon.mode: 'svg'`，覆盖 UIcon 及 Nuxt UI 内部图标。CSS 模式首次出现新图标时会向 head 前部插入带 `@layer` 的样式，本机 Chromium 实测会使 Emoji 字体短暂回退，产生闪烁与宽度变化；不要只对 Header 局部修复，也不要用固定 Emoji 宽度或合成层提示掩盖问题。保留图标数据的现有客户端打包与系统 Emoji 兜底。

- 全局换行按内容语言决定，与设备无关：中文、日文使用 `word-break: break-all`，英文使用 `word-break: normal`；通过 `:lang()` 支持局部语言标注。Markdown 的 ProseP 按语言分别设置排版规则：中日文段落使用 `word-break: normal` 覆盖全局 break-all，按自然断行机会排版并按字符两端对齐；英文段落使用 `word-break: normal`、`hyphens: auto` 和按词两端对齐，根据 `lang="en"` 自动断词并添加连字符，保留 break-words 处理超长连续字符。各语言保留 text-pretty、两端对齐与末行左对齐；修改中日文规则时不得移除英文自动连字符。介绍行继续沿用全局策略；nowrap、代码、URL 等有明确用途的局部规则仍可覆盖。

- HTML 结构中，非必要不要直接写 `style` 内联样式，优先使用 Tailwind CSS 与 Nuxt UI 提供的能力完成样式表达。
- `<style scoped>` 不是禁用，但应只用于 Tailwind CSS / Nuxt UI 难以表达的复杂状态、动画、第三方组件覆盖或结构性样式；普通布局与视觉优先留在模板 class。
- `:style` / 内联 `style` 只用于运行时计算值、第三方库注入 HTML、canvas / map 等 Tailwind CSS 无法静态表达的场景；静态样式不要回退成 inline style。

## 主题与 Design Token

- 优先复用 `app.config.ts` 中的 Nuxt UI 主题配置，以及 `assets/styles/base/tailwind.css` 中的 design token，不要在页面里重新发明一套颜色、表面层级、尺寸语义。
- 颜色、语义色、表面层级、字号与字体倾向，优先通过 token 与 class 表达，不要在局部组件里散落硬编码色值。
- `--color-surface-*` 当前定义在 base CSS 中，未注册为 Tailwind `@theme` 颜色；引用时使用 `bg-(--color-surface-2)`、`from-(--color-surface-0)` 等显式变量类，不使用不会生成 CSS 的 `bg-surface-*` / `from-surface-*`。修改后检查构建 CSS 的实际声明，不能仅凭 Build 通过判断视觉类有效。
- 对 Nuxt UI 组件的定制，优先走 theme / config / class 扩展，不要为了一个局部视觉点把整个组件手写替换掉。

## 评论点赞用户列表

- `MessageCommentItem.likedByUsers` 由现有点赞关联查询返回，只选取公开昵称、用户名及头像所需字段；头像尊重用户选择的身份，缺失时使用 UAvatar 的文字回退，不伪造头像或新增逐条用户请求。不修改数据库 Schema。接口同时保留 `likedByUsernames` 旧字段，兼容发布前已打开的客户端。

## 偏好页 Bangumi 收藏

- 偏好页 Markdown 使用单个 `BangumiCollection`，旧 `BangumiAnime` 与 `BangumiBooks` 入口继续委托该组件并设置初始分类。统一复用真实 API 请求、占位刷新、状态徽标、图片懒加载与统计，不在前端伪造收藏记录。
- 去掉组件外框、内边距和顶部标题。作品链接不带外圈 hover 背景与额外 padding；封面统一 160px 宽、5:7 比例，按用户要求以 object-cover 铺满图片区域，作品名保持 text-sm，改用 serif 并限制一行省略；列表和底部统计显式使用 font-normal，对齐贡献图字重，底部账户统计沿用 sans。封面统一使用可区分页面的 surface 底色和中性细描边，图片自身的白边也有明确轮廓。hover / 键盘聚焦时由独立的 20% 黑色遮罩以 200ms opacity 淡入变暗，状态徽标保持清晰，不缩放图片；封面父层 isolate 与圆角 clip-path、图片自身 rounded-lg 一起确保四角裁切。
- 横滑复用 `HorizontalScroller`，Bangumi 通过 itemSelector 按真实作品起点每次只切换一张，不按整个视口翻页；`CarouselNavigation` 统一负责作品集、贡献图、Bangumi 与 ImageCarousel 的按钮和渐变外观。ImageCarousel 保留循环、预览与不同图片高度的位置定制，其他组件沿用 hover 导航与各自的窄屏规则，不复制导航模板或样式。
- 只显示一排当前分类作品，不加外框或分隔线；统计紧跟列表。作品列表下方左侧显示用户提供的 Bangumi SVG 标志、账户名和本地化“番剧 / 书籍”切换按钮，右侧直接显示“想看 XX / 在看 XX / 已看 XX”或“想读 XX / 在读 XX / 已读 XX”，不使用 UTooltip，并在右侧统计文字前放置 chart-column 图标。底栏与 GitHub 贡献图底栏统一使用 slate-600 / dark:slate-300 加深文字；GitHub 的 Commits 前使用 git-branch 图标，并保留统计日期 UTooltip。底栏使用固定 Grid 列，组件宽度不足 672px 时固定两行靠左：账户行保留分类切换按钮，统计行保持 text-sm（14px），统计保持单行，超出可用宽度时往返循环滚动；组件宽度至少 672px 时保留左右布局和 text-sm，统计按剩余宽度布局，不在宽度动画途中自动 flex 换行。SVG 删除官网布局 class 并优化路径，保留 viewBox、路径与原色。统计来源与原有接口一致。

- 偏好页使用单个 `BangumiCollection`，底栏按紧凑的“番剧 / 书籍”按钮、Bangumi Logo、用户名排序；按钮 text-xs、20px 高，切换同一排封面，默认番剧，分别记住横向滚动位置。两个分类预加载真实 API；旧 MDC 包装入口保持兼容。右侧统计按当前分类整段模糊交叠淡出、淡入，移除 out-in 空档；文字层按目标宽度布局，分别测量两分类并保留共同所需高度，避免宽度过渡中临时换行与移除文本导致高度抖动，通过实际文本测量和 400ms width 过渡带动统计图标平滑移动。`BangumiWorkCard` 管理固定框内的独立图片、标题与徽标层；切换时按位置复用作品外框，封面尺寸、描边与标题预留高度固定；保留旧封面底层，新封面预解码后由 SkeletonImage 在上方以 260ms opacity 显现、延后 40ms 的 480ms blur 对焦、600ms translateY(24px → 0) 收尾柔和交叠，旧图仅轻微变糊，完成后移除；不使用 clip-path 揭幕或 scale 缩放，不出现移动的硬裁切边界。标题在独立固定行高区域内模糊和 translateY 切换；状态标签保持 z-30 最高层，仅使用 opacity 与 translateY，不跟随图片裁切。不重建整个收藏区；图片切换预解码后用 CSS blur、opacity 与轻微 translateY 交叠，旧图保留至覆盖完成；不再逐帧操纵或取消整卡 WAAPI 动画，快速切换忽略过期解码结果；已开始的封面揭示完整播放，期间只记住最新目标，完成后再切换，禁止新点击取消揭示帧或把半显图片重置透明，卸载清理，所有动画尊重 reduced-motion。共享导航的边缘渐变仅一侧可滚动时宽 48px / sm 64px，两侧可滚动时宽 96px / sm 128px，宽度与显隐一起过渡，窄屏原有隐藏规则不变。

- Bangumi 封面严格由 IntersectionObserver 控制 src：SSR 与未进入可见区域的卡片不渲染带地址的 img，rootMargin 为 0，遵守横向滚动容器裁切与页面视口交集。离屏卡片切换分类时清除旧地址，不赋值新分类地址；重新进入视口才加载。只有可见卡片为交叠动画预解码替换图片，离屏、再次切换或卸载时取消过期解码并拒绝应用结果；浏览器原生 loading=lazy 仅作辅助，不能代替 src 门控。合并组件可以获取两分类的真实 JSON 元数据，但隐藏分类不挂载封面图片。

- 横滑导航按钮统一沿用 ImageCarousel 的 scale-90 / opacity-0 到 scale-100 / opacity-100 的 200ms 显隐，ImageCarousel 使用与作品集及 Bangumi 相同的 32px 按钮和 16px 图标。ImageCarousel 窄屏只隐藏渐变，保留 32px 导航按钮；仅显式开启 cycle 的多图循环时两侧按钮始终可用；默认非循环时索引限制在首尾，首张隐藏左按钮、末张隐藏右按钮，连续点击也不回绕，装饰性的半透明邻图不决定循环行为，继续显示半透明相邻卡片。手机端每张图片宽度上限为容器 84cqw；auto-width 横图同时按比例降低高度，确保一张完整横图能放进视口。Bangumi 封面区域 select-none，两层图片均禁止原生拖拽。

- Bangumi 底栏的 Logo 与用户名属于同一个账户链接块，内部 gap-2；账户块与左侧分类切换按钮之间使用 gap-3。统计文字左侧图标使用 translate-y-px 做基线对齐。

- Bangumi 两分类请求通过 allSettled 隔离失败，分别保存数据与错误；分类入口在加载和失败时仍可用，手动重试仅请求当前分类，占位刷新仅请求仍为占位的分类。封面解码成功后才替换，失败展示当前作品的占位和独立重试按钮，不把失败当成成功移除旧图，不长期保留其他作品的旧封面；首次加载与 reduced-motion 同样执行解码校验，过期结果不落地。

- Bangumi 封面图层按图片 URL 设置稳定 key：出场时保留已解码的原 SkeletonImage 组件与内部 DOM 图片，仅将其降为底层；新地址创建独立的透明前景图层，完成初始样式提交后播放过渡。禁止通过改写同一个可见 img 的 src 来回切换缓存图片，避免往返分类时短暂闪出新图再隐去。

- Bangumi 底栏统计保持单行，溢出时按首页偏好文字的 56px/s 速度往返循环滚动，首尾各停留 1500ms；离屏或页面隐藏时暂停，减少动态效果时停止滚动。项目作品集与 Bangumi 的共享轮播渐变保留 400ms transform 沿左右各自边缘滑入、撤回，并同步在显示时恢复 blur(0) / opacity 1、隐藏时过渡到 blur(6px) / opacity 0，减少动态效果时直接切换。模糊作用于渐变填充层，不模糊卡片；ImageCarousel 保持原有动画，按钮保持原有显隐节奏。Bangumi 新旧封面统一使用按 URL 稳定 key 的 SkeletonImage，保留其骨架和图片渐显动画；前景转为旧封面时复用同一组件，不替换 DOM。等待新封面的 ready 事件并提交初始帧后才启动外层 600ms 交叠，仅监听外层自身最长的 transform 过渡结束（保留 650ms 兜底），避免较短的 opacity 或内部渐显事件使旧封面提前移除。

- Bangumi 封面由独立的 absolute 外层负责定位及切换动画，SkeletonImage 只负责内部骨架与图片渐显。禁止在 SkeletonImage 自带 relative 的根节点上叠加 absolute 来定位交叠层，否则两个定位 utility 冲突会让新封面落入文档流、被裁切，并在旧层移除时跳回顶部。验收须核对新旧层的实际位置与连续可见帧，不能只检查 opacity 数值。

### 对焦交接节奏

- 首页副标题、音乐和 ACG 封面、偏好页分类切换采用“透明度先显现、模糊随后消退、位移最后停稳”的分属性节奏；旧内容退场更短、位移与模糊更轻。首页六秒最小阅读窗口、作品名独立淡化、菜单与导航提示既有动效不变。
- Bangumi 标题入场延后 80ms，再分别播放 200ms opacity、360ms blur、460ms translateY；退场为 160ms opacity 与 200ms blur / transform。徽标保持 220ms 清晰反馈，不跟随封面模糊。底栏统计入场延后 60ms，使用 200ms opacity、320ms blur、400ms translateY；退场 140–180ms。封面预解码、离屏加载门控、稳定 URL key 和连续点击排队保持原逻辑，不为错峰增加网络等待。
- 所有新节奏尊重 prefers-reduced-motion，关闭 delay 与 transform / filter 动画。不逐帧测量布局，不给重复 SVG 背景添加动态滤镜。
