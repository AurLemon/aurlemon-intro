# Creative Commons 标识

SVG 来自 [Creative Commons 官方下载页](https://creativecommons.org/mission/downloads/)，保留官方图形与 viewBox，供 `/meta` 的 CC BY-NC-SA 4.0 内容许可链接使用。

页面用 CSS 将前景设为 `currentColor`、圆形白底设为透明，以适配本站 slate 色和明暗主题，源文件保留原样。
